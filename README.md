# 🎡 SpinPick

**Spin. Pick. Done.**

SpinPick is a modern and minimal random-choice wheel that helps you make decisions in a fun and satisfying way. Add your choices, spin the wheel, and let SpinPick randomly choose one for you.

## ✨ Features

* 🎡 Interactive random-choice wheel
* ➕ Add unlimited choices
* 🗑️ Remove individual choices
* 🧹 Clear all choices
* 🎯 Fair random selection
* ✨ Smooth spinning animations
* 🎉 Animated winner popup
* 🏆 Spin history
* 🔄 Spin Again option
* 🚫 Remove winner after spin
* ⌨️ Spacebar support for spinning
* 🔊 Optional sound effects
* 💾 Local storage support
* 📱 Fully responsive design
* 🌸 Soft baby-pink and white UI
* ⚡ Fast and lightweight

## 🖥️ How It Works

1. Enter a word or choice.
2. Add it to the wheel.
3. Add as many choices as you want.
4. Press **SPIN**.
5. Watch the wheel spin.
6. SpinPick randomly selects one of your choices.
7. Use **Spin Again** or continue adding choices.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/noahxo1/spinpick.git
```

Navigate into the project:

```bash
cd spinpick
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.
